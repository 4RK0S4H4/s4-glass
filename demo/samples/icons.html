The comparison. You asked for Solar Bold Duotone in every S4 Glass app; here it sits next to Phosphor Duotone, in the app's own rail, buttons, chips and table rows, light and dark, in the accent colour. Nothing in the toolkit has changed yet. In every pair below, Solar is on the left and Phosphor on the right.

A · Solar Bold Duotone. One set for everything. Nav, tabs and empty states already use it, so this extends it to buttons, chips and row actions (today those use Solar Linear). About 8,700 names exist, so a missing icon is rare. Heavier at 12–14px than Phosphor.

B · Phosphor Duotone. Lighter, rounder, about half the file weight for the same names, with a 1,500-name duotone set. Every icon in the toolkit changes (including nav and tabs), and the faded layer is a separate path, not a group, so the active-state rule needs a small change.

C · Solar for apps, Phosphor for web pages. Solar Bold Duotone in app screens; Phosphor Duotone for marketing pages and feature cards. Two sets to load, document and keep in step, and a page that links into an app shows two styles side by side.

RecommendedA · Solar Bold Duotone. It is the set the toolkit's nav, tabs and empty states already use, it is the one you asked for, and one set keeps every app and the Bank Reconciliation app identical. The weight at 14px is the only real cost; it holds up in the chip and row-action samples below. If a 12–14px icon ever looks too dense, use Linear only there.
Recommendation basis: S4 Glass rules and your earlier decisions. The front-end design skill was not available in this session, so it was not used.

How the second layer works

A duotone icon is a solid shape plus a faded shape. Both sets draw the faded half in the same colour at a lower opacity, so the accent colour is the only thing that changes: the toolkit sets color and the icon follows. Solar fades its half to 50%, Phosphor to 20%. Last column: the faded half in Accent Light at full strength, a two-tone option that works the same way in both.
