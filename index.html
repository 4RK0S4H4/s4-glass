Start a new app

Plain CSS and a little JavaScript. No build step, no dependencies.

  1. Copy toolkit/ next to your page (or start from a template).
  2. Load s4.js first, then fonts.css and s4.css.
  3. Set three values: --accent, --accent-2, --accent-light.
  4. Build from the components; check with tools/check_css.py and screenshots at 390, 1280 and 1920.
